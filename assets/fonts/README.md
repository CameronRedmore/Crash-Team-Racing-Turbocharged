game's GPLv3 licence. Keep each font's accompanying licence and attribution
files with every copy, including source archives and binary packages.

## Provenance

Luckiest Guy was copied unchanged from the official Google Fonts repository:
https://github.com/google/fonts/tree/ac011ec057856b010986a55104323d63cada00f8/apache/luckiestguy

`LuckiestGuy-Regular.ttf` SHA-256:
`cfbdd68a039f92df51cf3721506af6242e64594c6325fe0bedbeff3fe385d980`

Fuzzy Bubbles and its licence match the official Google Fonts copies:
https://github.com/google/fonts/tree/a60a77e14f28abd4ef243a1b5dfc48df0cec5205/ofl/fuzzybubbles

`FuzzyBubbles-Bold.ttf` SHA-256:
`f18fa58c66cf2540800f10ae4c9ae315c89149c41ace2a394c5efca7354c4ea8`

Luckiest Guy's original copyright and trademark notices remain embedded in the
TTF and are reproduced in its accompanying attribution file. Its upstream
directory contains no separate NOTICE file. Fuzzy Bubbles' full OFL text and
copyright are shipped beside its TTF. Font names and binaries have not been
modified, subsetted, or relicensed.

The OFL permits bundling with the game and requires keeping the font under the
OFL; the font may not be sold by itself. Any future modified OFL font must also
respect applicable Reserved Font Names. Apache 2.0 requires the licence copy
and applicable attribution notices; modified files need change notices.

Crash-a-Like is supplied by the player. It is not included in source or binary
release packages, and is not covered by either bundled font's licence.
